# KidKalc

A visual calculator for kids. Every answer is shown with pictures first — dots, carrots, baseballs, flowers, apples or stars — and the number appears only when you ask for it.

- **Add:** two groups pop in, then slide together.
- **Take away:** items wiggle and fly off, leaving faded outlines.
- **Times:** a garden planted row by row, with skip counting.
- **Share:** items dealt into baskets, with any leftovers set aside.

Basic Mode uses numbers 1 to 12. No build step — open `index.html` in a browser.
